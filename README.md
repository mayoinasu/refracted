REFRACTED

A horror puzzle game where you have to rotate the boxes to refract the light into another box until it reaches the sensor.

Demo video:

https://github.com/user-attachments/assets/a400ad85-2ec0-496a-a0d7-207af6a2e5bf

Link to play this game: https://mayoinasu.itch.io/refracted

**In this game, all you have to do is:**
* Rotate the boxes to refract the light into another box until it reaches the sensor.
* Solve the puzzle quickly before your character gets hungry. If they do, the game will restart from your last checkpoint.
* Eat food to restore your character's hunger bar.
* Read or interact with objects to uncover hints about the lore.

This is actually my first puzzle game, so I don't have too much experience on designing levels. But other than designing the box, 
the hardest challenge when making this game is basically the box. To be honest, at first I wanted to make the box able to rotate in 8 directions, while the tutorials that I found on YouTube only do 4 directions. At first, I thought I could change it easily, but it turns out impossible to do (or maybe I haven't try that hard).

Another things that hard for me is making the hint. I’m actually having some story in my head about the lore, but when I made it into a hint, it just got blurred. Also, to make the player have to open all the hints in the corridor before doing the next level, I have to make a lot of conditionals; which I know there are better options for doing this, but I’m still a beginner. I’m still using conditionals too much, but I finally made everything work! Also, by adding the BGM, sound effects, and making the checkpoints; There are many things that I just tried in this game!
